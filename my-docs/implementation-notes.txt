Tips:

Change model to save usage limits, Opus 4.5 consumes more but its best for complex tasks like planning or writing complex code. Sonnet 4.5 is pretty good overall, Haiku 3.5 is good for simple stuff like changing font-size and color on your CSS.

Type /clear to clear context window if you are about to start a new task that is unrelated to the previous task

Claude creates a README.md file in your root directory which explains the project. That's a Best Practice if you're using GitHub. If you make changes to the project structure or if you add features to the project, ask Claude to review your codebase and update the README.md file accordingly

Create a documentation folder with your plan.md file and other reference files if you see fit and keep them up to date (if you make changes ask Claude to update the files)

Refer to the pages Getting Started/Talking to Claude and Reference/Prompts for more tips and best practices.
